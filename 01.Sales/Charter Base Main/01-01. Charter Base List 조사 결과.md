# SalesOpportunityListForm 조회조건별 상세·신규 팝업 (현행 vs AS-IS)

> 현행: `SalesOpportunityListForm.xfdl`과 서브폼 A~K
> AS-IS: `D:\20260506_somFreezingSource\...\*.xml`
> A 서브폼 TR 수정을 반영한 뒤의 상태 기준

## 1. 조회조건이 팝업에 미치는 영향

| 조회조건                                        | 컴포넌트      | 팝업에 미치는 영향                                                              |
| ----------------------------------------------- | ------------- | ------------------------------------------------------------------------------- |
| **C/B Type**                                    | `cb_cbType`   | 상세·신규 팝업 Form을 결정 (주 분기 조건)                                       |
| **Type** Working(1) / Performing(2)             | `rd_type`     | **Form은 바뀌지 않음.** 조회 테이블(WRK/PERF)과 결산 중 read_only 여부만 달라짐 |
| **Type** OTC / LCH / Monthly (FF일 때)          | `ff_type`     | FF의 서브폼과 신규 Form을 결정                                                  |
| **Type** Swap / Swap+Option / Monthly (FT일 때) | `rd_ftType`   | FT의 서브폼과 신규 Form을 결정                                                  |
| **Only Vessel**                                 | `in_cb`       | 상세 경로가 Only Vessel 전용 경로로 바뀌고, 신규 버튼은 비활성                  |
| **CB type 고정**                                | `chk_cb_type` | 영향 없음 (다음 접속 때 기본 C/B Type으로 쓸 값만 저장)                         |

### C/B Type에 따른 Type 영역 (AS-IS와 현행 동일)

| C/B Type                               | Type 영역 표시                         | Working/Performing          |
| -------------------------------------- | -------------------------------------- | --------------------------- |
| TR, LN, VH, TK, BV, VV, TV, TT, DD, ID | Working / Performing                   | 선택 가능                   |
| FF                                     | OTC / LCH / Monthly (`rd_type`은 숨김) | Performing으로 고정         |
| FT                                     | Swap / Swap+Option / Monthly           | Performing으로 고정, 비활성 |
| WS, BL                                 | Working / Performing                   | Performing으로 고정, 비활성 |
